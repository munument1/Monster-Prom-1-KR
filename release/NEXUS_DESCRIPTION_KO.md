# Monster Prom 1 한국어 패치

몬스터 프롬 1편의 비공식 한국어 번역 패치입니다. 본편과 게임에 수록된 Second Term 텍스트, 선택지·결과 문구, UI 및 주요 이미지 문구를 한국어로 옮겼습니다.

## 주요 내용

- 추출 언어 사전 **34,208/34,208개 위치** 번역·적용.
- 메인 이벤트 1~976번, 선택지와 결과 문구 번역.
- 한글 폰트, 기본/Second Term 로고, 메뉴, 학교 팻말, 상점, 주요 소품 및 엔딩 캡션 한글화.
- 파일 버전 검사와 원본 백업, 원본 복원 기능이 있는 Windows 패처 제공.

이 수치는 추출한 언어 사전 기준입니다. 모든 화면의 줄바꿈 검사와 모든 문장의 독립 감수를 완료했다는 의미는 아닙니다. 첫 초기 공개판이며, 오역·잘림 제보를 받아 보완할 예정입니다. 배경 장식 문구와 작가 서명 등은 원문을 유지하는 경우가 있습니다.

## 설치 방법

1. Monster Prom을 설치하고 종료합니다.
2. ZIP 전체를 압축 해제합니다.
3. `MonsterPromKR-Patcher.exe` 실행 → 게임 폴더 선택 → **한글 패치 설치**.
4. 게임 언어를 **ENGLISH**로 설정합니다.

Python 별도 설치는 필요하지 않습니다. `patches`와 `patch_manifest.json`은 패처 옆에 두세요.

### Steam Deck / 설치 EXE 없이 수동 설치

`Monster-Prom-1-KR-v0.1-Overwrite.zip`을 선택하세요. 게임을 종료하고 원본 `MonsterProm_Data`를 직접 백업한 뒤, ZIP의 `MonsterProm_Data`를 게임 폴더에 복사·병합·덮어쓰기합니다. 기존 폴더를 삭제하면 패치에 없는 게임 파일이 사라지므로 병합하세요. 게임 언어는 ENGLISH입니다.

Steam Deck에서는 먼저 게임의 호환성 설정에서 Proton을 선택해 Windows판을 설치하세요. 이 배포본은 Windows판+Proton을 대상으로 안내하며 Linux 네이티브판과 Steam Deck 실기 실행은 미검증입니다. 덮어쓰기판에는 자동 버전 검사·백업 기능이 없습니다. 자세한 절차는 ZIP의 `설치 안내_SteamDeck.txt`에 있습니다.

## 지원 환경과 제거

Windows 64비트 / Monster Prom 1편. 제작 기준 Steam Build ID **20786767**이며, 설치 시 원본 파일 해시를 대조합니다. 호환되지 않는 파일은 덮어쓰지 않습니다. 다른 모드로 수정한 설치본은 순정 상태로 복원한 뒤 설치하세요.

제거할 때는 게임 종료 → 패처의 **원본으로 복원**을 누릅니다. 게임 폴더의 `_MonsterPromKR_Backup`을 보존하세요. 설치 작업용으로 약 3GB 이상의 여유 공간을 권장합니다.
