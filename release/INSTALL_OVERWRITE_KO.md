# Monster Prom 1 한국어 패치 v0.1 · 파일 덮어쓰기판

설치 프로그램 없이 `MonsterProm_Data` 폴더를 복사하는 배포본입니다. 기존 v0.1 Windows 패처와 같은 25개 수정 파일을 담았습니다.

## Steam Deck 설치

이 파일은 **Windows판 게임을 Proton으로 실행하는 구성**을 대상으로 합니다. SteamOS 기본 Linux판 에셋과의 호환성은 검증하지 않았습니다.

1. 게임을 종료하고 Steam Deck을 데스크톱 모드로 전환합니다.
2. Steam에서 Monster Prom의 **속성 → 호환성 → 특정 Steam Play 호환성 도구 사용**을 켜고 Proton을 선택합니다. Steam이 Windows판을 다운로드하면 완료될 때까지 기다립니다.
3. **속성 → 설치된 파일 → 찾아보기**로 게임 폴더를 엽니다. `MonsterProm.exe`와 `MonsterProm_Data`가 있는지 확인합니다.
4. 게임 폴더의 기존 `MonsterProm_Data`를 다른 위치에 복사해 백업합니다. 덮어쓰기판에는 자동 백업·버전 검사 기능이 없습니다.
5. `Monster-Prom-1-KR-v0.1-Overwrite.zip`을 압축 해제합니다.
6. 압축을 푼 폴더의 **`MonsterProm_Data` 폴더를 게임 폴더에 복사**합니다. 기존 폴더와 병합하고 같은 이름의 파일을 덮어씁니다. 기존 폴더를 통째로 삭제하지 마세요. 패치에 없는 원래 파일도 필요합니다.
7. Steam에서 게임을 실행하고 언어를 **ENGLISH**로 선택합니다.

게임 모드로 돌아간 후에도 Proton 설정을 유지하세요. 패치 후 호환성 도구를 해제하거나 게임 파일 무결성 검사를 하면 파일이 바뀌거나 패치가 해제될 수 있습니다.

Valve의 Proton 설정 안내: https://help.steampowered.com/en/faqs/view/7DD4-C618-182E-0E49

## Windows 수동 설치

게임을 종료하고 기존 `MonsterProm_Data`를 백업한 뒤, 위 5~7번과 같이 복사·병합·덮어쓰기 합니다. 설치 프로그램을 선호한다면 별도 `Monster-Prom-1-KR-v0.1.zip`을 사용하세요.

## 지원 버전·검증 범위

- Monster Prom **1편 Windows판**, 제작 기준 Steam Build ID **20786767**.
- Steam Deck은 **Windows판 + Proton** 구성으로 안내합니다. **Steam Deck 실기 실행은 아직 확인하지 않았습니다.**
- 기존 v0.1과 수정 파일 25개의 SHA-256이 모두 같습니다. ZIP 해제·덮어쓰기·백업 복원은 별도 테스트 폴더에서 검증합니다.
- 다른 버전이나 다른 모드로 수정한 게임에 덮어쓰면 충돌할 수 있습니다. 버전이 맞는 순정 설치본을 기준으로 사용하세요.
- ZIP 안의 `ORIGINAL_SHA256SUMS.txt`와 `PATCHED_SHA256SUMS.txt`는 각각 원본/패치 파일 목록과 해시입니다. 원한다면 게임 폴더에서 `sha256sum -c`로 검사할 수 있습니다. 해시 목록을 검사할 때도 파일은 변경되지 않습니다.
- 여유 공간은 압축 해제·복사·백업을 고려해 약 3GB 이상을 권장합니다.

## 원본으로 복원

게임을 종료하고 직접 보관한 원본 파일을 돌려놓으세요. 백업이 없다면 Steam의 파일 무결성 검사로 원본을 복구할 수 있습니다. 수동 덮어쓰기판으로 설치한 뒤 Windows 설치 패처의 복원 버튼을 사용하려면 해당 패처가 만든 백업이 별도로 있어야 합니다.
