# Monster Prom 1 한국어 패치 v0.1

## 설치

1. Steam에서 Monster Prom을 설치하고 게임을 종료합니다.
2. 배포 ZIP의 **전체 내용**을 한 폴더에 압축 해제합니다. `patches` 폴더와 `patch_manifest.json`을 실행 파일 옆에 두세요.
3. `MonsterPromKR-Patcher.exe`를 실행합니다. Python 별도 설치는 필요하지 않습니다.
4. `MonsterProm.exe`가 있는 게임 폴더를 선택합니다. Steam의 게임 속성 → 설치된 파일 → 찾아보기로 위치를 확인할 수 있습니다.
5. **한글 패치 설치**를 누르고 완료될 때까지 기다립니다.
6. 게임을 실행하고 언어를 **ENGLISH**로 선택합니다.

대상은 Windows 64비트용 **Monster Prom 1편**입니다. 제작 시 설치본의 Steam Build ID는 **20786767**입니다. 실제 호환 여부는 25개 대상 파일의 SHA-256으로 검사합니다. 지원하지 않는 버전이나 다른 모드로 수정한 파일이면 설치를 중단합니다. 게임 폴더가 수정 가능한 위치에 있어야 하며, 설치 작업용으로 약 **3GB 이상 여유 공간**을 권장합니다.

## 원본 복원

게임을 종료한 뒤 같은 패처에서 **원본으로 복원**을 누릅니다. 원본은 게임 폴더의 `_MonsterPromKR_Backup`에 보관됩니다. 복원을 원한다면 이 폴더를 지우지 마세요. 복원 후에도 백업은 유지합니다. **설치 상태 검사** 버튼으로 현재 파일을 확인할 수 있습니다.

이 패치를 개발 중인 폴더에서 이미 적용했거나, 다른 패치가 설치되어 지원 대상과 다르다고 표시되면 Steam 파일 무결성 검사로 순정 상태를 복구한 뒤 설치하세요. 무결성 검사를 하면 이 한글 패치도 해제됩니다.

## 포함 내용과 현재 상태

- 추출 언어 사전 34,208개 위치 번역·적용, 메인 이벤트 1~976번의 대사·선택지·결과 포함.
- 한글 폰트 연결, 로고·메뉴·장소 팻말·상점·엔딩 사진 등 이미지 한글화.
- 시작 잡지 표지 폭과 학교 장소 팻말 외곽 투명도 수정 포함.
- 원본 게임 실행 파일·DLL·게임 전체 에셋 파일은 포함하지 않습니다. 원본 설치본에 적용하는 변경분입니다.

첫 공개 버전입니다. 모든 문장의 독립 감수와 모든 게임 화면 확인을 마친 정식 완성판은 아닙니다. 화면별 줄바꿈·일부 장문 잘림·오역은 추가 점검 대상입니다. 배경 장식 간판, 책/게임 제목, 작가 서명 등은 원문을 유지하는 경우가 있습니다.

번역은 영어 슬롯을 사용하므로 ENGLISH 선택 시 한국어가 표시됩니다. 세이브 파일은 패처에서 수정하지 않습니다. 게임은 패처가 자동 실행하지 않습니다.
