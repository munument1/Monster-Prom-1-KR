## 2026-10-25 · 수동 덮어쓰기 배포본 추가

같은 v0.1 수정 파일25개를 담은 `Monster-Prom-1-KR-v0.1-Overwrite.zip`을 추가했습니다. `MonsterProm_Data` 폴더를 게임 폴더에 병합·덮어쓰기하는 방식으로 설치 EXE가 필요하지 않습니다. 원본은 직접 백업하세요. 기존 Windows 설치형 ZIP은 그대로 유지합니다.

Steam Deck은 Windows판 게임을 Proton으로 실행하는 구성을 대상으로 안내하며, Linux 네이티브판 및 Steam Deck 실기 실행은 아직 검증하지 않았습니다. 설치 방법은 덮어쓰기판에 포함된 `설치 안내_SteamDeck.txt`를 확인하세요.
