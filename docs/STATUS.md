## 2026-10-23 · 사용자 확인 반영, v2 및 번역 묶음 01·02

- 사용자 화면에서 Second Term 로고가 영어로 남아 있는 것을 확인. 기본 로고와 별도인 전용 텍스처를 한글 생성 이미지로 교체.

- `UIFont` 8개의 `mDynamicFont`를 한글 폰트에 연결하고 기존 비트맵 재질·아틀라스 참조를 해제. 기본 크기는 각 원래 폰트 크기를 유지.
- ‘시작·온라인·설정·갤러리·모드 도구·종료’ 이미지 버튼 6개를 생성·교체. 같은 아틀라스의 슬라이더·장식은 원본 유지.

- 영어 원문 324개에 대한 한국어 번역 데이터 추가. 본편·Second Term 프롤로그 36개 위치, 언어 사전 총 39개 위치, UI 표 405개 위치, 씬 라벨 351개 위치에 대응. 같은 문구가 여러 위치에 쓰이므로 합산을 고유 번역량으로 보지 않음.
- `apply_translation_batch.py`로 원본 추출 위치에 번역 재주입. 변수·치환자·주요 서식 태그 보존 검사 및 저장 후 바이트 검증 통과.
- 각 수정 단계의 적용 직전 백업과 최초 게임 원본 백업 유지. 현재 최종 설치 파일은 16개, 수정 오브젝트는 누적 398개.
- **수정 후 실행·화면 재확인은 사용자 대기 중. 본문 전체 번역과 이미지 전체 번역은 미완료.**

## 2026-10-23 · 1편 초기 분석 및 로컬 테스트

- Unity 2017.4.40f1, Mono 관리 어셈블리 구조 확인.
- 에셋/씬 38개를 조사하고 TextAsset·Font·MonoBehaviour 읽기 오류 0개 확인.
- TypeTreeGeneratorAPI 0.0.10의 문자열 배열 타입과 MonoBehaviour 헤더 정렬을 `unity_support.py`에서 보정.
- 언어 사전의 영어 항목 34,208개 추출. 고유 영어 문구는 30,822개이며 출현 위치 기준 단어 수는 약 510,702개.
- UI 표 686개, 씬 라벨 818개, 기타 검토용 문자열 546개, 코드 문자열 4,509개를 별도 추출. 중복과 비번역 문자열이 있으므로 합산한 값을 고유 번역량으로 사용하지 않음.
- 번역 항목에 파일명·path ID·필드 경로, 가능하면 이벤트명·화자와 타 언어 참조를 보존. 한국어 필드는 빈 상태로 생성.
- 게임 내 CJK 폰트의 한글 완성형 11,172자 지원 확인. 한글·영문·문장부호 등을 추린 폰트로 15개 폰트 오브젝트를 임시 교체.
- 설정 메뉴 일부와 프롤로그 첫 5개 문장을 영어 슬롯에 시험 적용. 중복된 문장 위치도 함께 변경.
- 이미지 생성으로 ‘몬스터 프롬’ 한글 로고 시안 제작. 기본·축소 텍스처 3개에 크기와 투명 영역을 맞춰 적용.
- 새 그림이 기존 영문 로고의 타이트 메시 외곽에 잘리지 않도록 스프라이트 3개의 메시를 사각형으로 변경.

- 게임 원본과 로고 적용 직전 폰트 테스트 상태를 각각 로컬 백업. 적용·복원·재적용을 해시로 확인.

## 남은 범위

이미지에 박힌 다른 UI 문구는 아직 번역하지 않았습니다. DLC 전용·중국어 로고는 교체하지 않았습니다. 본편과 함께 직렬화된 추가 콘텐츠 데이터가 추출물에 포함될 수 있으므로 번역 착수 시 콘텐츠 구분이 필요합니다. 원래 영문 서체를 보존하는 폰트 구성, JSONL 번역 재주입, 태그·변수 검증과 배포용 패치 생성 방식도 후속 작업입니다.
